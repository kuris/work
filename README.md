# 직장인 업무도구 (work.chatgpts.kr)

직장인을 위한 무료 업무 계산기 및 실무 도구 모음 서비스입니다.
복잡한 세금과 4대보험 공제액부터 연차, 퇴직금, 시급, 근무일수, 업무 메모까지 간편하게 사용할 수 있습니다.

## 🛠️ 제공 도구 목록

1. **연봉 실수령액 계산기** (`/salary`, `salary.html`)
   - 연봉/월급 기준 선택 입력
   - 비과세액, 부양가족 수, 20세 이하 자녀 수 반영
   - 4대보험(국민연금 4.5%, 건강보험 3.545%, 장기요양 12.95%, 고용보험 0.9%) 및 근로소득세/지방소득세 자동 산출
   - 예상 월 실수령액 및 연 환산 실수령액 표시

2. **퇴직금 계산기** (`/retirement`, `retirement.html`)
   - 입사일/퇴사일 달력 지정에 따른 총 재직일수 계산
   - 최근 3개월 기본급 및 연간 상여금 반영 1일 평균임금 산정
   - 근로기준법상 1년 이상 계속근로 시 법정 퇴직금 예상액 도출

3. **연차 계산기** (`/annual-leave`, `annual-leave.html`)
   - 근로기준법 제60조 기준 연차 산출
   - 1년 미만 입사자: 1개월 개근 시 1일(최대 11일)
   - 1년 이상 재직자: 15일 기본 부여 + 3년차부터 2년마다 1일 근속 가산(최대 25일)
   - 사용 연차 차감 후 잔여 연차 실시간 계산

4. **시급/월급 계산기** (`/hourly`, `hourly.html`)
   - 2026년 법정 최저시급(10,030원) 기본 반영
   - 주 15시간 이상 근무 시 법정 주휴수당 포함/미포함 토글
   - 월급 ➔ 소정근로시간(209시간) 기준 환산 시급 역산 기능

5. **근무일수 계산기** (`/workdays`, `workdays.html`)
   - 시작일과 종료일 사이 총 일수, 평일 근무일수(월~금), 주말 일수(토/일) 계산
   - 빠른 기간 프리셋(1주, 2주, 1개월, 3개월, 6개월) 제공

6. **업무 메모 & 체크리스트** (`/memo`, `memo.html`)
   - 오늘의 할 일과 업무 메모 작성 및 완료 체크
   - 브라우저 `localStorage` 연동으로 새로고침 및 재방문 시에도 데이터 유지 (서버 저장 없음)

7. **관리자 센터** (`/admin`, `admin.html`)
   - Supabase `page_views` 통계 연동 (화면 조회수 및 시간대별 접속 분석)
   - 타 프로젝트 관리자 간 원클릭 '서비스 전환' 메뉴 탑재

## 🚀 기술 스택 & 구조
- **Core**: Vanilla HTML5, CSS3, Modern JavaScript
- **배포**: Vercel (`vercel.json` cleanUrls 및 rewrites 지원)
- **통계/인증**: Supabase Client (관리자 전용 및 track.js)
- **외부 종속성 최소화**: 라이브러리 없이 순수 함수 기반 계산 모듈(`js/calculators.js`)로 가볍고 빠른 반응성 보장
